#    pip install -r rag_pipeline/requirements.txt
#
#  Two OPTIONAL extras live in their own files, because each one pulls in
#  torch or a large dependency tree that most users never need:
#
#    requirements-rerank.txt   only if retrieval.reranker.backend = huggingface
#    requirements-eval.txt     only if you run run_evaluation.py (RAGAS)
#
#  WHY THEY WERE SPLIT (this was a real bug, not tidying):
#  this file used to contain BOTH `langchain-community>=0.2.0` and
#  `langchain-community==0.3.7`. pip resolves the last one it sees, so the
#  version you got depended on line order - and the RAGAS pin silently
#  became the version used by the whole project. Each package is now pinned
#  in exactly one place.

# -- Semantic chunking -------------------------------------------------------
# langchain-experimental provides SemanticChunker (splitters/semantic_chunker.py).
# langchain-community provides the OllamaEmbeddings adapter it needs.
# NOTE: the `langchain` meta-package is deliberately NOT listed - no file in
# this project imports it. It was pure download weight.
langchain-community==0.3.7
langchain-experimental>=0.0.60

# -- Embeddings and generation (offline, via a local Ollama server) ----------
# One package for both: semantic_chunker.py and embedding/embed_generator.py
# use it to embed, generation/llm_client.py uses it to answer.
# Install Ollama itself separately (https://ollama.com), then pull the exact
# tags named in settings.yaml under `models:`. `run_doctor.py` checks this
# for you and prints the pull commands you are missing.
ollama>=0.3.0

# -- Table normalization (HTML tables -> sentences a model can embed) --------

# -- Vector store (local, persistent, no server) -----------------------------
