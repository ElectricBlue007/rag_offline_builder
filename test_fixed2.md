# Chonkie RAG Library

This is a sample document without proper headings.

Installation

Install Chonkie using pip:

pip install chonkie

Or using uv:

uv add chonkie

## Requirements

- Python 3.8+
- numpy
- transformers

from chonkie import SemanticChunker
